## 2. 후킹 구조 (표지 프레임, 이미지에서 읽은 자막)
"[N살]이 되어서 매일 하고 있지만… / [M살]에 시작했으면 더 좋았을 [숫자]가지 습관"

| 요소 | 역할 | 우리 버전 |
|---|---|---|
| 현재 나이 호명 | 화자의 현재 시점, 전문성·경험 암시 | 43살 (약사 본인 나이, 본인 확인) |
| "매일 하고 있지만" | 현재진행 + 겸손한 역접 | 실제로 매일 하는 습관만 사용 |
| 과거 나이 호명 | **타겟 호명**("35살") | 35세 이후 타겟과 일치 |
| "시작했으면 더 좋았을" | 후회 + 손실 회피 | 위협이 아니라 정보 제안으로 사용 |
| 숫자 리스트 | 약속된 분량, 끝까지 볼 이유 | 레퍼런스 12 → **3가지**(근거 확인된 수) |

## 3. 캡션 구조 → 43세 약사 버전으로 변환
| # | 레퍼런스 캡션의 블록 | 역할 | 우리 버전 | 따라 하지 않는 것 |
|---|---|---|---|---|
| 1 | 짧은 약속 문장 + ⤵️ | 첫 줄 후킹 | "43살이 되어서 매일 하고 있지만… 35살에 시작했으면… 3가지 ⤵️" | "누구나 가능" 같은 단정 |
| 2 | 📌 댓글에 [키워드] → **받을 자료 이름** | 스크롤 전 CTA | 📌 댓글에 [라벨체크] → 근거 정리본 + 공동구매 링크(광고) | - |
| 3 | 1인칭 자기소개(약점 노출) | 신뢰·공감 | "피부 관리에 진심인 약사" + **본인 경험 슬롯** | 체중·병력 같은 개인 이력을 대신 지어내는 것 |
| 4 | ⁉️ 속말 질문 4개 | 독자 대변 | 35세 이후 피부 고민 질문 3개 | - |
| 5 | 연표(숫자 이력) | 서사 | **본인 경험 슬롯**(실제 경험만) | 가짜 이력·수치 |
| 6 | 전환점 "40대가 되니…" | 목적 재정의 | "오래 가는 습관을 근거로 골라 봤어요" | - |
| 7 | 수칙 소개 | 해법 | **근거 확인된 습관 3가지 + 출처** | 근거 없는 수칙 |
| 8 | 체감 결과 서술 | 설득 | **사용 안 함** | "피부가 좋아졌어요" 류의 효과 암시 |
| 9 | 확신 선언 | 마무리 | 한계와 주의사항 + 키워드 재요청 | "이 기본도 못 지키면 효과 없어요" 같은 단정·공포 |

## 4. 빈틈 → 차별화
1. 수칙에 출처·근거가 없음 → 습관마다 임상시험·기관 근거와 **한계**까지 표기
2. 자료(정리본)는 캡션에서 내용이 안 보임 → 목차와 근거를 미리 보여 주고 DM으로 상세·제품 안내
3. 결과 암시 → 근거가 부족한 부분은 "부족하다"고 말함
