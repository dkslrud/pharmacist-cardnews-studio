# 06. DM 발송 설계: 댓글 키워드 → 정리본 + 제품 링크

## 1. 흐름
```
영상·캡션: 댓글에 [라벨체크]
   ↓
댓글 작성자 (자발적 요청)
   ↓  ① 공개 댓글 답글(선택): "DM 보내드렸어요 🤍 (광고 안내가 포함돼요)"
   ↓  ② DM 1통: 정리본 + 제품 안내(광고) + 구매 링크
   ↓
답장이 오면 → ③ 수동 응대(FAQ 템플릿)
```
- 정책 제약 때문에 첫 DM 이후 추가 자동 발송이 제한될 수 있습니다(**확인 필요**). 그래서 정리본과 제품 링크를 **첫 DM 한 통**에 담았습니다.
- 발송은 수동 또는 자동 DM 도구로 할 수 있습니다. 자동 도구를 쓰면 인스타그램 정책, 개인정보 처리(닉네임 저장 범위), 키워드 매칭 오류를 확인하세요.

📢 [광고] 공동구매 제품 안내

## 3. 하루 총량 문구 분기 (표시사항 확인 후 선택)
| 확인 결과 | 문구 |
|---|---|
| 하루 비타민C 총량이 2,000mg 이하 | "하루 총량이 상한(2,000mg, 미국 NIH 성인 기준) 이내예요." ("안전해요" 금지) |
| 하루 비타민C 총량이 2,000mg 초과 | "하루 총량이 상한 2,000mg을 넘는 양이에요. 설사·복통이 생길 수 있고, 고용량의 피부 효과는 근거가 충분하지 않아요. 신장 질환이나 복용 중인 약이 있다면 구매 전에 먼저 상담해 주세요." **필수** |
| 하루 총량 미확인 | DM에서 제품 링크를 제외하고 정리본만 발송 |

## 4. 답장 응대 템플릿 (수동)
| 질문 | 응답 방향 |
|---|---|
| "하루에 몇 포 먹어요?" | 제품 표시사항의 섭취방법을 그대로 안내. 개인별 용량 조언은 약사 상담으로 연결 |
| "효과 있나요?" | "효과를 약속드릴 수는 없어요. 피부와 비타민C의 근거는 정리본에 정리했어요" |
| "복용 중인 약이 있어요" | 구매·복용 전 약사·의사와 상담 권고 (약 이름 확인 후 안내) |
| "신장이 안 좋아요 / 결석 있었어요" | 먼저 의사·약사 상담 권고 (제품 권유 금지) |
| "임신·수유 중이에요" | 먼저 의사·약사 상담 권고 |

## 5. 광고·판매 규칙
1. DM의 제품 안내 첫머리에 **[광고] 공동구매** 표기
2. 구매 압박 금지: "마감 임박", "오늘만", "품절 위기" 등 불안·조급 유발 표현 금지
3. 효능 단정 금지: "피부가 맑아져요", "노화 방지" 등 금지. 인정된 기능성 문구는 식약처 원문 확인 후 그 범위에서만
4. 제품 가격·혜택은 확정된 사실만 기재
5. 개인정보: 댓글·DM 정보는 응대 목적에만 사용, 불필요하게 저장·공유하지 않음
6. 링크에 UTM 등 추적 파라미터를 붙이면 전환(DM → 구매)을 측정할 수 있음

## 6. 측정 지표
댓글 수 → DM 발송 수 → 링크 클릭 수 → 구매 수 (공동구매 판매 도구 기준). 영상은 평균 시청 시간과 시청 유지.
