# 07. 검수 결과 (v2)

## 콘텐츠
| 항목 | 결과 | 조치 |
|---|---|---|
| 타겟(35세 이후 칙칙한 피부·노화) 연결 | 충족 | 후킹에 "35살"을 호명하고, 피부 습관 3가지(자외선 차단·비타민C·메가도스 확인)로 구성 |
| 첫 5초 호기심 | 충족 | 레퍼런스의 나이 대비 + 숫자 약속 구조 적용 |
| 약사 전문성·신뢰 | 충족 | 습관마다 임상시험·기관 근거와 한계를 표기 |
| 흐름 | 충족 | 습관 ①(확실한 근거) → ②(반전: 비타민C 근거 부족) → ③(메가도스 확인 기준) → CTA |
| 광고처럼 느껴지는지 | 충족 | 영상·캡션 본문에는 제품 효능·함량 없음. 제품은 DM에서 [광고] 표기로 안내 |
| 건강 주장 근거 | 충족(조건부) | 컷 3~7은 원문(초록 포함) 확인. 한국 기준·식약처 문구는 미사용 |

## 요청 반영 점검
| 요청 | 반영 | 비고 |
|---|---|---|
| 레퍼런스 구조 그대로 | 후킹 문장 구조, 캡션 블록 순서(키워드 CTA → 서사 → 속말 질문 → 전환점 → 수칙) 유지 | 습관 개수는 12 → **3**으로 조정(근거 확인된 개수) |
| 43세 피부 관리 약사 화자 | 반영 | 본인 경험·"매일 하고 있다"는 **본인 확인 슬롯** |
| 결론을 메가도스의 중요성으로 연결 | **"메가도스를 고민할 때 확인할 기준"으로 연결** | "중요/효과적" 단정은 근거가 없어 사용하지 않음 (03 추가분 §2) |
| 제품 판매 링크 DM 발송 | 반영 | DM 1통에 정리본 + 제품 안내 + 링크, 광고 표기, 하루 총량 분기 문구 |

## 레이아웃
레퍼런스 레이아웃만 적용(9:16, 중앙 인물, 중앙 정렬 4줄 자막 2+2, 외곽선). 문구·인물·색·폰트 미사용. 확인 범위: 표지 프레임 1장.

## 규정 점검
| 항목 | 결과 |
|---|---|
| 질병 예방·치료 암시, 효과 단정 | 없음 (레퍼런스의 체감 결과·단정 선언은 사용하지 않음) |
| 공포·구매 압박 | 없음 (DM에서 마감 임박·한정 표현 금지 규칙 명시) |
| 상한·상호작용·질환 주의 | 영상 컷 7, 캡션, 정리본, DM에 포함 |
| 항산화 보충제 일반화 | 베타카로틴 결과를 비타민C에 일반화하지 않음 |
| 가짜 경험 | 없음 (본인 경험 슬롯, 본인 확인 항목) |
| 광고 표기 | **미완료**: 공동구매 표기 문구 확정 필요 |
| 제품 효능·함량 | 사용 안 함 (표시사항 미확보) |

## 게시 전 완료해야 할 것
1. 피치힐 비타민C 3000 + 아연 표시사항과 구매 링크 → DM 템플릿·정리본 6번 칸 작성, 하루 총량 분기 문구 선택
2. 공동구매 광고 표기 문구
3. 약사 본인 경험 2곳과 "43살, 매일 하고 있다" 사실 확인
4. DM 발송 방식과 인스타그램 정책(첫 DM 이후 추가 발송 제한 등) 확인
5. 습관을 12가지로 늘리려면 나머지 근거 조사를 의뢰
6. 게시 후 평균 시청 시간, 댓글 수, DM 전환 점검
