# 02. 레퍼런스 분석 (예시)

수집: 2026-10-11, Apify `apify/instagram-scraper`(게시물 1건), 표지 프레임은 `apify/web-fetch`(raw)로 확인. 인물 사진·영상은 저장소에 싣지 않았습니다.

## 1. 공개 지표
| 항목 | 값 |
|---|---|
| 계정 | 롱진 \| Long:zine (@long.zine) |
| 형식 | 릴스(영상), 67.8초, 9:16 |
| 게시일 | 2026-03-23 |
| 재생수 | 327,668 |
| 좋아요 / 댓글 | 1,816 / 117 |

성과의 원인은 단정하지 않습니다. 저장·공유 수는 공개 수집이 안 되어 미확인입니다.

## 2. 구조 (캡션 기준, 문장은 옮기지 않고 요약)
- **후킹**: 메가도스의 이점을 말하면서 "피하거나 용량을 달리해야 하는 경우도 있다"를 함께 제시 (이점 + 주의 반전)
- **전개**: 전문가 발언 인용 → 번호 7개 정리 → 용량 설정 방법 → 부작용(위장)과 용량 조절 → 면책 문구(신장 결석·위장 질환 상담)
- **숫자**: 메가도스 기준 용량, 복용 분할 방법, 효과를 체감하는 기간을 구체적으로 제시
- **CTA**: 행사 참여 안내 (제품 판매 없음)
- **음성·자막 전체**: 수집하지 못함 (캡션과 표지 프레임으로만 분석)

## 3. 성공 공식 (가설, 단정 아님)
1. 이점과 주의를 같이 던지는 후킹
2. 용량·기간 같은 숫자로 구체화
3. 전문가 본인 경험으로 신뢰 형성

## 4. 빈틈 → 우리 콘텐츠의 차별화
| 빈틈 | 우리의 대응 |
|---|---|
| 효과 체감 기간 등 수치에 출처 표기가 없음 | 컷마다 기관·논문 출처를 자막으로 표기 |
| 제시된 용량이 공공기관 상한과 어떻게 다른지 설명 없음 | 권장량·상한(2,000mg, NIH 성인 기준)과 비교 |
| 흡수율·용량 관계 설명 없음 | 용량이 늘수록 흡수율이 떨어진다는 근거(NIH) 제시 |
| 제품 선택 기준 없음 | 라벨에서 1회 섭취량·하루 총량·주의사항 확인법 제시 |

## 5. 화면 레이아웃 (표지 프레임 1장 확인)
| 요소 | 관찰 |
|---|---|
| 비율 | 9:16 세로 |
| 구도 | 인물 상반신 인터뷰 구도, 얼굴은 화면 상단~중앙, 약간 측면 시선 |
| A 카테고리 라벨 | 헤드라인 바로 위, 작은 크기, 좌측 정렬 |
| B 헤드라인 | 화면 하단 1/3, 좌측 정렬 3줄, 굵은 고딕 |
| C 로고 | 헤드라인 아래 중앙, 작은 워드마크 |
| 배경 | 박스·딤 처리 없이 자연 배경 위 자막 |

**적용 범위**: 위 레이아웃(비율, 구도, A·B·C 위치와 줄 수)만 가져옵니다. 문구, 인물·영상, 로고, 음악, 색·폰트는 가져오지 않습니다. 표지 외 장면의 구도는 확인하지 못했습니다.
