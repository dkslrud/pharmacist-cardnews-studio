# 04. 영상 스크립트 (예시): 비타민C 3000mg, 많이 먹을수록 좋을까요?

릴스 9:16 / 약 57초 / 약사 본인 출연 / 레퍼런스 레이아웃 적용

## 공통 화면 레이아웃 (레퍼런스에서 추출한 것만 적용)
- 인물 상반신 인터뷰 구도, 얼굴은 화면 상단~중앙
- **A** 소형 카테고리 라벨 → **B** 하단 1/3 좌측 정렬 최대 3줄 헤드라인 → **C** 중앙 소형 로고 자리 (내 계정 로고)
- 박스·딤 없이 자연 배경 위 자막. 색·폰트는 Canva 브랜드 키트 (미설정 시 가독성 기준 기본값)

## 컷 6 작성 규칙 (표시사항 확인 후 적용)

|---|---|
| 하루 총량이 2,000mg 이하 | "하루 총량이 상한(2,000mg, 미국 NIH 성인 기준) 이내예요." 처럼 사실만. "안전하다" 단정 금지 |
| 하루 총량이 2,000mg 초과 | "하루 총량이 상한 2,000mg을 넘는 양이에요. 설사·복통이 생길 수 있고, 신장 질환이나 복용 중인 약이 있다면 먼저 상담하세요." 필수 |
| 1회 섭취량·하루 총량 미확인 | 컷 6 삭제하고 정보성 영상으로만 게시 (제품명의 "3000"만으로 섭취량 단정 금지) |
| 식품 유형이 건강기능식품 | 식약처 인정 기능성 문구 범위에서만 효능 표현 (원문 확인 필요) |

## 촬영·편집 가이드
- 촬영: 약사 본인 상반신, 자연광, 세로 촬영. 라벨 클로즈업은 실제 영양제 2~3종(타사 로고는 가리기)
- 자막: 컷마다 하단 1/3, 좌측 정렬, 한 줄 14자 안팎. 근거 출처는 화면 최하단에 작게 "출처: NIH ODS, 2025.7.31"
- 편집: 컷 전환은 1~2초 간격의 점프컷, 숫자는 자막에서 굵게 강조
- 내레이션 길이: 컷별 초당 약 5음절 기준으로 점검함
