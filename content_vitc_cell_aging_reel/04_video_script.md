# 04. 영상 스크립트: 35세 이후 피부 노화, 비타민C 3000mg이 답일까요?

릴스 9:16 / 약 68초 / 원본 스크립트(롱진 릴스 DWOh4w4BgcA)의 7컷 구조 유지 / 약사 본인 출연 / 레퍼런스 레이아웃 적용 / 목표: 댓글 → DM

## 입력
| 항목 | 내용 |
|---|---|
| 타겟 | 35세 이상, 세포 노화로 인한 피부 노화를 고민하는 여성 |
| 제품 | 피치힐 비타민C 3000 (공식 표시사항·USP **확인 필요**) |
| 광고 | 공동구매 (표기 문구 확정 필요) |
| 목표 | 댓글 유도 (댓글 키워드 → DM으로 정리본 + 제품 안내) |
| 썸네일 | Canva, 컬러·폰트 기본값 |

## 공통 화면 레이아웃 (레퍼런스 표지 프레임에서 추출한 것만 적용)
- 9:16, 인물 상반신 인터뷰 구도 (얼굴은 화면 상단~중앙)
- **A** 헤드라인 위 소형 카테고리 라벨 → **B** 하단 1/3 좌측 정렬 최대 3줄 헤드라인 → **C** 헤드라인 아래 중앙 소형 로고(계정명) 자리
- 박스·딤 없이 자연 배경 위 자막. 색·폰트는 기본값(가독성 기준)

## 훅·시청 지속 설계 (제작 원칙, 효과는 게시 후 인사이트로 검증)
| 장치 | 위치 |
|---|---|
| 타겟 호명("35세 이후") + 질문형 후킹, 첫 3초 안에 핵심 질문 | 컷 1 |
| 오픈 루프: "근거부터 볼게요", 끝에 정리본 예고 | 컷 2, 7 |
| 반전: 관찰 연구가 있다 → 하지만 단정할 수 없다 | 컷 3 → 4 |
| 컷 안에서 자막 덩어리 교체(2~4초마다 시각 변화) | 컷 2~6 |
| 숫자 강조(4,025명, 2,000mg, 50%) | 컷 3, 5 |
| 가치 제시 직후 CTA | 컷 7 |

게시 후 확인: 평균 시청 시간, 시청 유지 그래프(제공되는 경우), 댓글 수, DM 전환.

## 제품 처리
- 영상에는 제품명·함량·효능을 넣지 않았습니다. 제품은 DM의 광고 칸에서 표시사항 확인 후 안내합니다.
- 하루 총량 문구 분기(DM 정리본 기준)
  | 확인 결과 | 문구 |
  |---|---|
  | 하루 비타민C 총량이 2,000mg 이하 | "하루 총량이 상한(2,000mg, 미국 NIH 성인 기준) 이내예요" (안전 단정 금지) |
  | 하루 총량이 2,000mg 초과 | "상한 2,000mg을 넘는 양이에요. 설사·복통이 생길 수 있고, 고용량의 피부 효과는 근거가 충분하지 않아요. 신장 질환이나 복용 중인 약이 있다면 먼저 상담해 주세요." 필수 |
  | 미확인 | DM에서 제품 링크 제외, 정리본만 발송 |

## 썸네일 (Canva, 컬러·폰트 기본값)
- 9:16, 레퍼런스 레이아웃: A 소형 라벨 "영양제" / B 좌측 정렬 3줄 "35세 이후 피부 노화, / 비타민C 3000mg이 / 답일까요?" / C 하단 중앙 계정명 자리
- 화면 상단~중앙은 약사 본인 사진을 넣을 영역으로 비워 둠 (직접 사진 삽입)
- 프로필 격자에서 위아래가 잘릴 수 있어 핵심 문구는 중앙에 배치

## 촬영·편집 가이드
- 약사 본인 상반신, 자연광, 세로 촬영. 컷 1은 카메라 쪽으로 다가가는 동작 후 멈춤
- 자막은 컷마다 B 위치(하단 1/3, 좌측 정렬), 외곽선 처리. 출처는 화면 최하단에 작게 표기
- 내레이션은 초당 약 5음절 기준으로 점검했고, 말투는 해요체

## 확인 필요
1. 피치힐 비타민C 3000의 식품 유형, 1회·하루 섭취량, 함량, 주의사항, 구매 링크, USP
2. 공동구매 광고 표기 문구
3. 컷 6 약사 본인 경험 (실제 경험만)
4. 한국 기준 수치와 식약처 인정 기능성 문구 원문
5. "세포 노화" 관련 인체 근거는 확인하지 못함 (컷 4에서 그대로 밝힘). 이 표현을 더 쓰려면 근거 조사가 필요합니다.
