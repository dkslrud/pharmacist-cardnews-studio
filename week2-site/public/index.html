클로드 코드는 매번 처음 만나는 직원입니다

그냥 "오메가3 릴스 대본 써줘"라고 하면 누구에게 파는지, 어떤 말투인지, 어떤 표현이 금지인지 모르는 채로 씁니다. 그래서 결과가 남의 계정 글처럼 나옵니다.

해결은 간단합니다. 폴더 하나를 만들고 내 정보를 md 파일로 넣어 둡니다. 클로드 코드는 그 폴더에서 시작할 때마다 파일을 먼저 읽고, 내 계정을 아는 직원처럼 일합니다. 2·3단계의 모든 분석과 각색이 이 파일들을 기준으로 이루어집니다.

공구 폴더 구조

레인보우약사_오메가3공구/ ├── CLAUDE.md # 일하는 규칙. 클로드 코드가 가장 먼저 읽는 파일 ├── 내계정.md # 나는 누구고, 누구에게, 어떤 말투로 ├── 판매제품.md # 공구 제품·기간·혜택·자주 받는 질문 ├── 광고규정.md # 쓰면 안 되는 표현, 기능성 인정 문구 ├── 레퍼런스/ # 2·3단계에서 분석한 영상·카드뉴스가 쌓이는 곳 └── 기획/ # 각색한 대본·카드뉴스 원고가 쌓이는 곳

md는 메모장처럼 글자만 있는 파일입니다. 클로드 코드에게 "이 폴더 구조로 만들어 줘"라고 하면 빈 파일까지 만들어 줍니다. 내용은 아래처럼 채웁니다.

md 파일 4개, 이렇게 채웁니다

CLAUDE.md 일하는 규칙
# 레인보우약사 공구 작업 규칙 - 작업을 시작하기 전에 내계정.md, 판매제품.md, 광고규정.md를 먼저 읽는다. - 모든 글은 내계정.md의 타깃과 말투로 쓴다. 한국어, 존댓말, 짧은 문장. - 분석 결과는 레퍼런스/에, 대본·원고는 기획/에 날짜를 붙여 md로 저장한다. - 숫자·연구 결과는 출처가 있을 때만 쓴다. 모르면 [확인 필요]라고 적는다. - 광고규정.md에 걸리는 표현이 나오면 고쳐 쓰고, 고친 곳을 따로 알려준다.
내계정.md 누가, 누구에게
계정 @rainbow_yak · 레인보우약사 정체성 서울대 약대 출신, 5살·3살 키우는 약사 엄마 타깃 30~40대 육아맘. 아이 영양제를 기준 없이 고르는 엄마 검색 키워드 아이 영양제, 아이 오메가3, 약사 엄마, 어린이집 면역, 초등 입학 준비 말투 약국에서 엄마에게 설명하듯 다정하게. 전문용어는 바로 풀어서 잘된 첫 줄 "🚨마그네슘 부족 신호🚨 3개 이상 해당 된다면"(9.7만) 안 된 첫 줄 "오메가3는"(367)
판매제품.md 무엇을, 언제
제품 알래스카 오메가 츄 패밀리 공구 10/12~18 · 사은품 콜라겐 20개 공구가·구성 [상세페이지에서 옮겨 적기] EPA+DHA 합계·원료 형태 [상세페이지에서 옮겨 적기] 섭취 연령·하루 섭취량 [상세페이지에서 옮겨 적기] 자주 받는 질문 몇 살부터? 하루 몇 개? 젤리면 당은? 들기름으로 대신 돼요? 실제 구매평 [받은 후기 원문 그대로 붙여넣기]
광고규정.md 쓰면 안 되는 것
- 질병 예방·치료 표현 금지 (예: "ADHD에 좋다", "면역질환 예방") - "최고", "유일", "100%" 같은 최상급·단정 표현 금지 - 기능성은 상세페이지의 인정 문구 그대로만. "~에 도움을 줄 수 있음" - 후기는 실제 받은 것만, 원문을 바꾸지 않는다. 효과를 약속하는 후기는 쓰지 않는다 - 먹기 전·후 효과를 비교하는 표현과 사진은 쓰지 않는다
✍️

빈칸은 반드시 직접 채웁니다.

함량, 가격, 후기처럼 제품마다 다른 사실은 클로드 코드가 지어내면 안 되는 부분입니다. 상세페이지와 실제 후기에서 옮겨 적으세요. 채워 둔 만큼 3단계 각색이 정확해집니다.

첫 번째 일: 내 계정 진단받기

폴더가 준비되면 1주차의 질문을 클로드 코드에게 던집니다. "알고리즘이 내 계정을 어떤 주제로 읽고 있을까?"

클로드 코드에게 이렇게
내 최근 릴스 링크 목록이야. Apify로 각 릴스의 첫 자막, 캡션 첫 줄, 조회수를 받아 줘. 그다음 내계정.md의 타깃·검색 키워드와 비교해서 1) 알고리즘이 내 계정을 어떤 주제로 읽을지 2) 주제별 조회 중앙값 3) 타깃 주제인데 조회가 낮은 릴스의 첫 줄을 어떻게 바꾸면 좋을지 표로 정리해서 레퍼런스/계정진단.md로 저장해 줘.

Apify 연결은 3단계에서 한 번만 하면 됩니다. 연결 전이라면 인스타 인사이트 화면을 캡처해 폴더에 넣어도 됩니다.

영상 콘텐츠 스크립트 분석 및 기획

준비: Apify 연결 (한 번만)

클로드 코드는 인스타 영상을 직접 열어 보지 못합니다. Apify를 연결하면 링크만 줘도 영상 원본, 자막(음성 받아쓰기), 캡션, 댓글, 조회수를 받아 와서 분석할 수 있습니다.

  1. 1
    Apify 가입 후 API 토큰 복사
    apify.com 가입 → Settings → API & Integrations → Personal API token 복사. 무료 크레딧으로 시작할 수 있습니다.
  2. 2
    터미널에서 클로드 코드에 연결
    아래 한 줄에서 내토큰 자리에 복사한 토큰을 넣어 실행합니다.
    claude mcp add --transport http apify https://mcp.apify.com --header "Authorization: Bearer 내토큰"
  3. 3
    연결 확인
    클로드 코드를 다시 켜고 /mcp를 입력해 apify가 connected로 보이면 끝입니다.
🔑

토큰은 비밀번호와 같습니다. md 파일이나 단톡방, 캡처에 남기지 마세요.

분석 틀: 다섯 칸으로 나눠 받습니다

"분석해 줘"라고만 하면 감상문이 나옵니다. 칸을 정해 주면 레퍼런스끼리 비교할 수 있고, 각색할 때 칸만 바꿔 끼우면 됩니다.

1 · 구성
전체 흐름과 컷
몇 초에 무엇이 나오는지, 컷 수, 화자, 길이
2 · 훅
첫 문장과 화면 글자
무엇을 묻거나 건드려서 멈추게 하는지
3 · 초반 3초
넘기지 않게 만드는 것
화면·소리·자막이 각각 무엇을 하는지
4 · 지속 장치
끝까지 보게 만드는 것
포맷 예고, 리스트 카운트, 화자 전환, 웃음, 고정 타이틀
5 · 마무리·반응
CTA와 댓글
무엇을 하라고 하는지, 댓글에 나온 수요·의심
클로드 코드에게 이렇게

3-2

카드뉴스 분석 및 기획

릴스가 사람을 데려오면, 카드뉴스는 사게 만듭니다. 특히 OPEN 카드뉴스는 상세페이지를 대신하므로 레이아웃과 필수 요소를 빠짐없이 분석해야 합니다.

분석 틀: 레이아웃 + 후킹 요소 + 필수 요소

분석 칸무엇을 보나
레이아웃몇 장인지, 비율(1080×1350), 장마다 맡은 역할, 큰 글자·작은 글자 위계, 색과 사진 배치
후킹 요소커버 한 장에서 멈추게 하는 문장, 숫자, 질문, 이모지. 2장으로 넘기게 만드는 장치
필수 요소아래 다섯 가지가 몇 번째 장에, 어떻게 들어갔는지. 빠진 요소도 표시

Before/After와 구매평은 건강기능식품 광고 규정을 먼저 봅니다.

Before/After는 효과 비교가 아니라 생활 장면으로 보여 줍니다(먹이기 전 실랑이 → 먹이는 루틴). 구매평은 맛·먹이기 편함·아이 반응처럼 효과를 약속하지 않는 후기를 고르고, 원문을 고치지 않습니다.

클로드 코드에게 이렇게
이 카드뉴스를 분석해 줘: [게시물 링크] Apify로 캡션·장수·댓글을 받고, 내가 레퍼런스/ 폴더에 넣은 캡처 이미지도 같이 봐 줘. ① 레이아웃(장별 역할, 글자 위계, 색) ② 후킹 요소(커버, 2장으로 넘기게 하는 장치) ③ 필수 요소 다섯 가지(혜택, 구성, 제한·파격, Before/After, 실제 구매평)가 몇 번째 장에 어떻게 들어갔는지, 빠진 건 무엇인지 표로 정리해서 레퍼런스/카드뉴스_[계정명].md로 저장해 줘.

캐러셀 이미지는 Apify로 받아도 열리지 않을 때가 있습니다. 캡처를 레퍼런스/ 폴더에 넣어 주면 문구와 레이아웃까지 정확하게 분석합니다.

각색: OPEN 카드뉴스 원고

클로드 코드에게 이렇게
레퍼런스/카드뉴스_[계정명].md의 레이아웃과 후킹 요소를 빌리고, 내계정.md, 판매제품.md, 광고규정.md를 기준으로 10/12 OPEN 카드뉴스 8장 원고를 써 줘. - 필수 요소 다섯 가지를 모두 넣고, 장마다 [역할 · 큰 글자 · 작은 글자 · 사진 지시]로. - 판매제품.md에 없는 숫자는 [확인 필요]로 비워 둬. - 캡션 첫 줄과 댓글 키워드도 같이 써 줘. 기획/OPEN카드뉴스_1012.md로 저장해 줘.
