# 인스타그램 콘텐츠 기획·제작 (약사용)

레퍼런스 URL(또는 주제)만 알려주면, 부족한 정보는 이 스킬이 질문으로 채웁니다. 모든 건강 관련 주장에는 근거를 붙이고, 확인하지 못한 내용은 추측하지 않고 "확인 필요"로 표시합니다.

## 0. 만드는 것

| 산출물 | 내용 |
|---|---|
| 레퍼런스 분석 | 후킹, 정보 순서, CTA, 근거 사용 방식, 공개 반응 수치 |
| 계정 분석 | 내 계정의 말투·반응·디자인 (공개 데이터만) |
| 근거 검증표 | 주장 / 근거 / 출처 / 확인 수준 / 사용 가능 문구 / 주의사항 |
| 카드뉴스 (레퍼런스가 카드뉴스·캐러셀일 때) | 기획안 + Canva로 만든 PNG 세트(4:5, 1080×1350) + ZIP |
| 영상 원본 스크립트 (레퍼런스가 릴스·영상일 때) | URL에서 추출한 음성 대본·화면 자막을 컷별 표로 정리 (구조 분석용) |
| 영상 스크립트 (레퍼런스가 릴스·영상일 때) | 원본 스크립트의 컷 구조를 유지하고, 제품·타겟·상황 정보로 내용을 바꾼 예시안 (시간·화면·자막·내레이션) |
| 캡션 | 후킹·공감·요약·CTA·해시태그 |
| 검수 결과 | 콘텐츠·디자인·마케팅 체크리스트 평가와 수정 내역 |

**제작 형태 규칙**: 레퍼런스와 같은 형식으로 만듭니다. 레퍼런스가 릴스·영상이면 영상 스크립트만 만들고(카드뉴스는 만들지 않음), 카드뉴스·캐러셀이면 카드뉴스를 만듭니다. 사용자가 다른 형태를 직접 요청한 경우에만 그에 따릅니다.

**디자인 적용 범위 규칙**: 디자인은 **레퍼런스의 레이아웃으로만 한정**합니다. (자세한 내용은 STEP 5)

## 1. 최초 1회 설정 (연동 가이드)

이 스킬은 두 가지 도구와 연결해 쓸 때 가장 좋습니다. 연결이 없어도 질문 기반 기획은 가능하지만, 자동 분석(Apify)과 PNG 제작(Canva)은 되지 않습니다.

| 도구 | 하는 일 | 없을 때 |
|---|---|---|
| **Apify** | 인스타그램 게시물·계정 수집, 블로그·논문 페이지 본문 수집 | 레퍼런스를 직접 붙여넣거나 캡처를 업로드해야 함 |
| **Canva** | 카드뉴스 디자인 생성, PNG 내보내기 | 텍스트 기획안과 시안 설명까지만 제공. Canva에 직접 입력해야 함 |

### 1-1. Apify 연동

**준비**
1. Apify 계정 만들기: https://console.apify.com/sign-up (무료 플랜은 매달 사용 크레딧이 제공되며 카드 등록 없이 시작할 수 있다고 안내되어 있습니다. 금액과 조건은 바뀔 수 있으니 https://apify.com/pricing 에서 확인하세요.)
2. 유료 Actor 실행은 사용량(크레딧)이 차감됩니다. 이 스킬은 실행 전에 Actor, 입력값, 예상 수집량을 먼저 알려주고, 수집량을 기본 해시태그당 30~50건 이내로 제한합니다.

**방법 A. Claude 앱(claude.ai / Claude Desktop) — 권장**
1. Claude에서 **Settings → Connectors** 로 이동
2. **Add → Add custom connector** 선택
3. 입력:
   - Name: `Apify`
   - Remote MCP server URL: `https://mcp.apify.com`
4. **Continue** → 자동 감지된 인증 설정을 그대로 두고 **Add**
5. 처음 연결할 때 브라우저가 열리면 Apify에 로그인하고 접근을 허용 (OAuth, API 토큰 입력 불필요)
6. 팀/기업(Team, Enterprise) 플랜은 조직의 Owner 또는 Primary Owner가 커넥터를 추가해야 합니다.
7. 새 대화를 열고 "Apify에서 웹 스크래핑 Actor를 검색해 줘"라고 요청해 Apify 도구가 보이는지 확인

**방법 B. Claude Code CLI(터미널)**
1. Claude Code에서 `/plugin install apify` 실행 (찾지 못하면 `/plugin marketplace add apify/apify-claude-code-plugin` 후 `/plugin install apify@apify`)
2. 안내가 나오면 `/reload-plugins`
3. `/mcp` 실행 → `plugin:apify:apify` 선택 → **Enable** → 다시 선택 → **Authenticate** → 브라우저에서 **Allow access**
4. 브라우저가 열리지 않는 환경(원격/서버)이면 Apify Console → Settings → Integrations 에서 API 토큰을 복사해 `export APIFY_TOKEN=<토큰>` 후 실행
5. 웹/원격 세션(claude.ai/code)에서는 `/plugin`을 쓸 수 없고, 환경의 허용 도메인에 `*.apify.com`을 추가해야 합니다.

**문제 해결**
- 도구가 보이지 않음: 커넥터 도구 권한이 "차단"이 아닌지(Always allow 또는 Ask first) 확인 → 커넥터를 삭제 후 다시 추가 → Claude 재시작
- "Unauthorized" 오류: 커넥터를 삭제 후 다시 추가해 로그인(OAuth) 재진행
- 인스타그램 수집 결과가 비어 있음: 비공개 계정, 로그인이 필요한 정보는 수집할 수 없습니다. 이 경우 게시물 캡처를 올려주세요.
- 이미지(색상·폰트) 분석이 안 됨: 이미지 주소가 차단되거나 만료될 수 있습니다. 대표 게시물 캡처 3~5장을 올려주세요.
- 공개 데이터만 수집하세요. 수집·활용은 인스타그램 이용약관과 개인정보 관련 법령을 지키는 범위에서 본인 책임으로 진행합니다. 댓글 작성자 아이디 등 개인정보는 보고서에 남기지 않습니다.

### 1-2. Canva 연동

**준비**
- Canva 계정이 필요합니다. Canva 도움말 기준으로 **Canva Pro 계정은 Canva의 AI 커넥터로 Claude에 연결**할 수 있습니다. (Education/Enterprise 계정에는 별도로 Canva MCP 서버가 안내됩니다.) 다른 플랜의 이용 범위는 Canva 도움말에서 확인하세요.
- AI 기능 사용은 Canva AI 크레딧이 매달 차감될 수 있고, Claude 사용 한도도 별도로 있습니다.

**연결 방법**
1. Claude에서 **Settings → Connectors** 로 이동
2. **Canva** 선택 → 사용할 Canva 계정으로 로그인 → 권한 화면을 읽고 **허용**
3. **새 대화**를 열고 대화 설정(Connectors)에서 **Canva를 켭니다.** (연결만 해두고 켜지 않으면 도구가 보이지 않습니다.)
4. "내 Canva 브랜드 키트 목록을 보여 줘"라고 요청해 연결이 되는지 확인

**제작 품질을 높이는 사전 설정 (권장)**
- Canva에서 **브랜드 키트**(브랜드 컬러, 폰트, 로고)를 미리 만들어 두면 스킬이 이를 불러와 카드에 적용합니다.
- 계정의 대표 카드뉴스 중 마음에 드는 디자인이 있으면 Canva에서 **브랜드 템플릿**으로 저장해 두세요. 매번 같은 틀을 쓸 수 있습니다.
- 제품 사진, 로고 등은 Canva에 업로드해 두거나 공식 이미지 링크를 알려주세요. (실제 제품과 다른 패키지·성분 표시는 만들지 않습니다.)

## 2. 시작 흐름과 자동 질의응답

### 2-0. 연동 점검 (대화 시작 시 자동)
1. 사용 가능한 도구에 Apify(예: Actor 실행, 웹 페이지 가져오기)와 Canva(디자인 생성/내보내기)가 있는지 확인합니다.
2. 없으면 사용자에게 `1. 최초 1회 설정`의 해당 항목을 안내하고, 연결 후 새 대화에서 다시 시작하도록 합니다. 사용자가 원하면 연결 없이 가능한 범위(질문 기반 기획, 텍스트 산출물)로 계속합니다.

### 2-1. 1차 질문 (분석을 시작하기 위한 최소 정보)
이미 말한 내용은 다시 묻지 않고 확인만 합니다. 질문은 한 번에 묶어서(최대 4개) 합니다.

1. **레퍼런스 URL** 또는 **주제·성분** (둘 다 없으면 주제를 먼저 묻습니다. URL이 없으면 주제로 검색해 레퍼런스를 직접 찾습니다.)
2. **만들 콘텐츠 형태**: 기본은 레퍼런스와 같은 형식(릴스·영상이면 영상 스크립트, 카드뉴스·캐러셀이면 카드뉴스)입니다. 다른 형태를 원하면 알려 달라고 안내하고, 레퍼런스가 없을 때만 직접 묻습니다.
3. **내 인스타그램 계정**(@아이디): 말투·반응 분석용. 없으면 건너뜀
4. **참고 자료가 있나요?**: 계정 캡처, 제품 페이지 URL, 논문 PDF (선택)

### 2-2. 자동 분석 (질문 없이 진행)
- 실행 전에 Actor, 입력값, 예상 수집량을 한 줄로 알립니다.
- 레퍼런스(10개 안팎)와 내 계정(최신 20건 안팎)을 분석하고 표 1개 + 성공 공식 3줄 + 빈틈 3줄로 보고합니다.
- 영상 레퍼런스는 **원본 스크립트(음성 대본·화면 자막)를 추출**해 컷별 표로 함께 보고합니다. (STEP 1 참고)
- 반응 수치를 가져오지 못하면 노출 순위 기준으로 선별했다고 밝히고, 성과가 높다고 단정하지 않습니다.
- 분석이 끝나면 곧바로 2-3 질문으로 넘어갑니다.

### 2-3. 2차 질문 (분석 결과를 보고 필요한 정보를 묻고 멈춤)
분석 결과를 근거로 선택지를 제시하며 묻습니다. 답을 받기 전에는 기획·제작을 시작하지 않습니다.
영상 레퍼런스이면 추출한 원본 스크립트 컷표를 먼저 보여 주고, "이 컷 구조를 기준으로 내 제품·상황에 맞춘 예시안을 만들겠다"고 안내한 뒤 질문합니다.

1. **타겟**: 누구에게 보여줄 콘텐츠인가요? (나이대, 성별, 상황, 고민) — 분석에서 보인 후보를 선택지로 제시
2. **홍보 제품과 USP**: 제품명, 식품 유형(건강기능식품/일반식품/의약품/화장품 등), 1회·1일 섭취량과 함량, 공식 제품 페이지 URL 또는 표시사항 사진, 내세우고 싶은 차별점
3. **광고 구분**: 자사 판매 / 공동구매 / 협찬 / 광고 아님 (표기 방식이 달라집니다)
4. **콘텐츠 목표**: 저장·공유 / 댓글·DM 문의 / 제품 페이지 방문 중 우선순위
5. **컬러·폰트**: Canva 브랜드 키트 사용 / 기본값 사용 (레이아웃은 묻지 않고 레퍼런스의 것을 사용)

### 2-4. 입력 요약 확인
받은 답을 표로 정리해 "이대로 진행할까요?"를 확인하고, 사용자가 수정하면 반영한 뒤 3단계로 진행합니다. 제품 USP 중 공식 자료로 확인되지 않는 항목은 표에 "확인 필요"로 표시합니다.

## 3. 진행 순서

### STEP 1. 레퍼런스·계정 분석 (Apify)
- Actor 우선순위
  - 인스타그램 해시태그: `apify/instagram-hashtag-scraper`
  - 인스타그램 게시물·프로필 상세: `apify/instagram-scraper`
  - 구글 검색(블로그·매체): `apify/google-search-scraper`
  - 특정 URL 본문: `apify/web-fetch`
  - 부족하면 Apify Store에서 적합한 Actor를 검색해 사용
- 선별 기준: 최근 1년 이내, 반응 높은 순, 카드뉴스는 슬라이드 5장 이상
- **레이아웃 추출**: 사용자가 준 레퍼런스(주 레퍼런스)의 화면 구성을 확인해 기록합니다.
  - 카드뉴스·캐러셀: 슬라이드별 요소 배치(제목·본문·이미지 영역 위치, 정렬, 줄 수, 강조 방식, 페이지 표기, 여백)
  - 릴스·영상: 화면 비율, 인물·피사체 구도, 자막·라벨·로고의 위치·정렬·줄 수, 장면 전환 구성
  - 이미지를 볼 수 없으면 레이아웃을 추정하지 않습니다. 이미지 주소를 Apify `apify/web-fetch`(raw)로 가져와 확인하고, 그래도 안 되면 화면 캡처를 요청합니다. 릴스는 표지 프레임만 확인되는 경우가 많으므로 확인 범위를 밝힙니다.
- **영상 원본 스크립트 추출** (레퍼런스가 릴스·영상일 때, 입력한 URL에서 자동 진행)
  - Actor: `steadyfetch/instagram-reel-transcript-scraper` — 입력 `reelUrls`(릴스 URL), `includeOnScreenText: true`. 음성 대본, 시간 구간(segments), 첫 3초 훅, 화면 자막(옵션), 영상 길이, 재생수·좋아요를 돌려줍니다. 시험 단가는 릴스 1건당 약 $0.01이며, 실행 전에 Actor·입력·예상 건수·단가를 알립니다.
  - 대안 Actor: `afanasenko/instagram-reel-script-extractor`(화면 자막과 훅·CTA 분해까지, 단가 높음), `memo23/instagram-reel-transcript-scraper`(Whisper, SRT/VTT), 인스타그램 외 영상 URL은 `themineworks/instagram-tiktok-video-transcript`
  - 추출 결과를 **원본 컷표**로 정리합니다: 컷 번호 | 시간 구간 | 음성 대본 | 화면 자막 | 역할(후킹·공감·정보·전환·CTA) | 길이(초)·글자 수

### STEP 3. 근거·제품 검증
조사 우선순위: ① 식약처·식품안전나라 ② 국내 영양소 섭취기준(보건복지부·한국영양학회) ③ 해외 공공기관(예: NIH Office of Dietary Supplements) ④ PubMed의 임상시험·체계적 문헌고찰 ⑤ 기타 신뢰할 수 있는 학술 자료

- 각 주장에 **확인 수준**을 붙입니다.
  - **A 원문 확인**: 해당 페이지·논문을 직접 열어 문구와 수치를 확인
  - **B 2차 확인**: 검색 요약·기사로만 확인 → 원문 확인 전에는 콘텐츠에 수치를 쓰지 않음
  - **C 미확인**: 찾지 못함 → 임의로 작성하지 않음
- 원문 열기: 일반 웹 조회가 막힌 환경에서는 Apify `apify/web-fetch`로 가져옵니다.
- 검증표 열: 핵심 주장 / 근거 / 출처 URL / 확인 수준 / 근거 유형(임상시험·메타분석·관찰연구·공공기관 기준) / 사용 가능 문구 / 주의사항

- 제품 확인 항목: 정식 제품명, 식품 유형, 1회·1일 섭취량과 함량, 원료, 제형, 섭취방법, 주의사항 표시, 제조·품질 정보. 제품명에 들어간 숫자만으로 실제 섭취량을 단정하지 않습니다.

## 4. 약사·건강 콘텐츠 안전 규칙 (항상 적용)

이 규칙은 일반적인 주의 사항이며 법률 자문이 아닙니다. 최종 게시 전 제품 유형에 맞는 표시·광고 기준을 확인하세요.

1. 질병의 진단·예방·치료·완화를 암시하는 표현 금지(건강기능식품·일반식품). 인정된 기능성 문구가 있으면 공식 문구 범위에서만 사용
2. 의약품(전문·일반)은 광고 제한이 있으므로 제품 소개 전에 해당 기준 확인을 먼저 안내
3. "확실히", "무조건", "완치", "부작용 없음" 같은 단정·과장 표현 금지. 근거가 약하면 "연구 결과가 엇갈려요", "도움을 줄 수 있어요" 수준으로 표현
4. 공포 조장 금지. 위험 정보는 대상(질환자, 복용 중인 약, 임산부 등)과 조건을 구체적으로 적음
5. 상한섭취량, 약물 상호작용, 기저질환 주의 문구 포함
6. 근거 없는 수치 만들기 금지. 출처를 열어 확인하지 못한 수치는 쓰지 않음
7. 국가별 기준을 섞지 않음(예: 한국 기준과 미국 기준은 구분해 표기)
8. 공동구매·협찬이면 광고 표기를 확정한 뒤 제작하고 캡션 첫머리 등 눈에 띄는 곳에 표기
9. 다른 계정의 문장·디자인을 복사하지 않음. 구조와 인사이트만 활용
10. 후기·체험은 실제 경험만 사용. 가짜 후기·수치 금지
11. 개인정보(댓글 작성자 등) 비수집·비게시

   `instagram-content-planner 스킬로 진행해 주세요. 입력: $ARGUMENTS`

**Claude 앱(claude.ai / Desktop)**

2. Settings에서 스킬(Skills) 항목을 열어 zip을 업로드하고 켭니다. (메뉴 이름과 위치는 앱 업데이트로 바뀔 수 있으니 Claude 도움말에서 "스킬 업로드"를 확인하세요.)
