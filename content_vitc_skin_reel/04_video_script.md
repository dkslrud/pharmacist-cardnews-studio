# 04. 영상 스크립트: 35세 이후 칙칙한 피부, 비타민C 3000mg이면 될까?

릴스 9:16 / 약 48초 / 약사 본인 출연 / 레퍼런스 레이아웃 적용 / 목표: 댓글 → DM 정리본

## 공통 화면 레이아웃 (레퍼런스에서 추출한 것만 적용)
- 9:16 세로, 인물 **화면 중앙**. 후킹 컷은 카메라 쪽으로 몸을 기울이는 동작(레퍼런스 구도)
- 자막은 **중앙 정렬 4줄 = 2줄(강조) + 2줄(보조)**, 화면 53~68% 구간, 박스 없이 외곽선 처리
- 로고·라벨 없음. 색·폰트는 브랜드 키트(미설정이면 가독성 기준 기본값. 레퍼런스 색은 사용하지 않음)
- 새 그래픽·삽입 화면은 추가하지 않고, 숫자는 자막 강조로만 표현

## 훅·시청 지속 설계 (제작 원칙, 효과는 게시 후 인사이트로 검증)
| 장치 | 적용 위치 |
|---|---|
| 나이 호명 + 질문형 후킹 | 컷 1 자막 "35세 이후", 첫 4초 안에 핵심 질문 |
| 오픈 루프(끝에 보상 예고) | 컷 2 "끝에 정리본도 드려요" |
| 2~4초마다 시각 변화 | 컷 안에서 자막 덩어리 교체, 점프컷, 줌 인 |
| 한 컷 한 메시지, 컷 길이 5~7초 이하 | 컷 3~7 |
| 결론 지연 + 반전 | 컷 3 "필요해요" → 컷 4 "그런데 근거는 부족" |
| 가치 제시 직후 CTA | 컷 8에서 정리본 목차 3가지를 보여 준 뒤 키워드 요청 |
| 루프 엔딩 | 마지막 문장이 첫 문장 질문의 답으로 이어지게 편집(재시청 유도) |

게시 후 확인: 인사이트의 평균 시청 시간, 시청 유지 그래프(제공되는 경우), 댓글 수. 수치로 효과가 확인되기 전에는 "효과가 좋다"고 단정하지 않습니다.

## 설계 메모
- **제품명·함량은 영상에 넣지 않았습니다.** 표시사항 확인 전이므로, 제품 안내는 DM으로 가는 정리본의 광고 칸에서 확인 후 작성합니다. 공동구매 광고 표기는 컷 8 자막과 캡션에 넣습니다.
- 컷 5·6은 제품 하루 총량이 상한 2,000mg을 넘을 가능성이 있어 일부러 상한과 주의를 앞에 배치했습니다(근거 있는 정보 → 제품 순서).
- 내레이션 길이는 초당 약 5음절 기준으로 점검했습니다. 약사 말투(해요체)에 맞춰 촬영 중 어미는 조정해도 됩니다.
- 촬영: 약사 본인, 세로, 자연광. 컷 1은 카메라 쪽으로 다가가는 동작 후 멈춤.
