확인 수준: **A** 원문을 열어 확인 / **B** 검색 요약·AI 요약·기사로만 확인 (원문 확인 전 수치 사용 금지) / **C** 미확인

## 2. 제품: 피치힐 비타민C 3000 + 아연
| 항목 | 확인 결과 | 확인 수준 |
|---|---|---|
| 정식 제품명, 식품 유형 | 공식 페이지 미확인 | **C** |
| 1회·하루 섭취량, 함량 | **구글 AI 요약**에 "1일 1포, 비타민C 3,000mg, 아연 약 8~8.5mg, 파우더, 60포"로 나옴. 출처가 불명확하고 AI 요약은 오류가 있을 수 있음 | **B (사용 금지)** |
| 원료, 부원료, 제형, 섭취방법, 주의사항, 제조·품질 | 미확인 | **C** |

**설계에 미치는 영향 (가정이 아니라 분기 규칙)**
| 표시사항 확인 결과 | 사용할 문구 |
|---|---|
| 하루 비타민C 총량이 2,000mg 초과 | "상한 2,000mg을 넘는 양"이라는 안내와 설사·복통 가능성, 신장 질환·복용 약 상담 문구 **필수**. "안전하다" 금지 |
| 하루 총량이 2,000mg 이하 | "상한 이내"처럼 사실만. "안전하다" 단정 금지 |
| 하루 총량 미확인 | 제품 안내를 DM 정리본에서 제외하고 정보 영상만 게시 |

영상에는 제품명·함량을 넣지 않고, 제품 안내는 DM 정리본의 "광고" 칸에서 표시사항 확인 후 작성하도록 설계했습니다.
