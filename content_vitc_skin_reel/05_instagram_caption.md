## 변경 포인트 (이전 캡션 대비)
| 구분 | 이전 | 변경 |
|---|---|---|
| CTA 위치 | 마지막에 저장·댓글 안내 | **첫 5줄 안에 키워드 + 정리본 이름**, 마지막에 한 번 더 |
| CTA 행동 | 저장 + 댓글 | **댓글 키워드 1개 → DM으로 정리본** |
| 미리보기 | 없음 | 정리본 목차 3가지를 캡션에서 미리 보여 줌 |
| 공감 | 일반 서술 | 타겟의 속말 질문 3개 + 약사 본인 경험 슬롯 |
| 근거 | 비타민C 위주 | 비타민C·아연·피부 리뷰 논문 출처 표기 |
| 제품 | 칸만 있음 | 캡션에서는 제품 효능·함량을 쓰지 않고 DM 정리본에서 안내 |

## 운영 메모
- 키워드는 효능을 암시하지 않는 중립 단어(라벨체크)로 제안했습니다. 다른 키워드로 바꿔도 됩니다.
- DM 발송은 수동 또는 자동 DM 도구로 할 수 있습니다. 자동 DM 도구를 쓰면 인스타그램 정책과 개인정보·수신 관련 기준을 확인하세요.
- 레퍼런스 캡션의 결과 암시(체감 변화), 단정적 선언 문장은 따라 하지 않았습니다.
