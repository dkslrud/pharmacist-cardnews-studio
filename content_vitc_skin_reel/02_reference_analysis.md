# 02. 레퍼런스 분석

수집: 2026-10-11, Apify `apify/instagram-scraper`, 표지 프레임은 `apify/web-fetch`(raw). 인물 이미지는 저장소에 싣지 않았습니다.

## 1. 공개 지표
| 항목 | 값 |
|---|---|
| 계정 | 윤여진 박사 \| 맘미언니 (@momme.unni) |
| 형식 | 릴스, 7.6초, 9:16 |
| 게시일 | 2026-05-01 |
| 재생수 / 좋아요 / 댓글 | 306,061 / 965 / 7,429 |

댓글 7,429건은 "댓글에 키워드를 남기면 자료를 보내 준다"는 CTA로 유도된 반응이라 콘텐츠 선호도와 같다고 보지 않습니다. 저장·공유 수와 영상 음성·자막 전체는 수집하지 못했습니다.

## 2. 영상 후킹 (표지 프레임)
- 나이 호명 + 숫자 리스트: "N살에 시작했으면 좋았을 12가지 습관"
- 영상은 7.6초 티저이고, 상세 정보는 자료(정리본)로 이전

## 3. 캡션 구조 분석 (댓글 → 정리본 전달 구조)
| 순서 | 레퍼런스 캡션의 역할 | 관찰 | 우리 캡션에 적용 |
|---|---|---|---|
| 1 | 첫 줄 후킹 | 짧은 약속 문장 + ⤵️ | 타겟 호명 + 질문형 후킹 + ⤵️ |
| 2 | **CTA를 맨 앞에 배치** | 📌 + 댓글에 [키워드] + **받을 것의 이름**(예: "○○ 12원칙")을 구체적으로 명시 | 스크롤 전 첫 5줄 안에 키워드와 정리본 이름을 둠 |
| 3 | 본문 전 | 1인칭 약점 노출 서사, 숫자 연표 | **약사 본인의 실제 경험 슬롯**(지어내지 않음) |
| 4 | 공감 | 독자의 속말을 ⁉️ 질문 4개로 대변 | 타겟의 속말 질문 3개 |
| 5 | 전환점 | 나이(40대) + 목적 재정의 | "고용량부터 찾기 전에 근거부터" |
| 6 | 결과 암시 | 체감 변화 서술 (근거 없음) | **따라 하지 않음** (효과 암시 금지) |
| 7 | 마무리 | 단정적 선언 | **따라 하지 않음** (단정 표현 금지) |
| 공통 | 형식 | 한 줄 10~20자, 줄바꿈 다수, 줄 끝 이모지, 해시태그 없음 | 해요체·짧은 줄. 하이킴 약사 계정은 해시태그 5개 안팎이라 5~7개 사용 |

**핵심 설계 원칙**: 댓글을 달면 **정리본**을 준다. 그래서 캡션과 영상 모두 "정리본에 무엇이 들어 있는지"를 먼저 보여 주고, 키워드 1개로 행동을 단순하게 만든다.

## 4. 성공 공식 (가설)
1. 나이 호명 + 숫자로 묶는 후킹
2. 개인 경험으로 공감을 쌓고 해법을 자료로 제공
3. 댓글 키워드 → 자료 발송의 낮은 행동 장벽

## 5. 빈틈 → 우리의 차별화
| 빈틈 | 대응 |
|---|---|
| 건강 수칙에 출처 표기가 없음 | 영상 자막·캡션·정리본에 기관·논문 출처를 표기 |
| 결과 암시 표현에 근거 없음 | 근거가 부족한 부분은 "부족하다"고 말함 |
| 자료의 내용이 캡션에서 안 보임 | 정리본 목차 3가지를 영상과 캡션에서 미리 보여 줌 |
